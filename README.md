# MC Skin Pack Generator

一个基于纯前端技术（HTML/CSS/JavaScript）开发的 Minecraft 基岩版皮肤包生成工具。无需安装，直接在浏览器中即可完成皮肤包的创建与导出。

## 功能说明

- **批量导入**：支持通过点击或拖拽上传多张 PNG 图片，或包含多张 PNG 的 ZIP 压缩包。
- **尺寸校验**：自动检测并过滤非标准尺寸的图片，支持 64x64、64x32、128x128 格式。
- **模型切换**：支持为每张皮肤单独选择粗臂（Classic）或细臂（Slim）模型。
- **3D 实时预览**：内置基于 Canvas 和 CSS 3D 的立体渲染器，支持拖拽旋转查看模型，实时叠加帽子层，支持粗/细臂外观切换。
- **自定义命名**：支持修改每个皮肤在游戏内的本地化显示名称。
- **一键打包**：自动生成所需的 `manifest.json`、`skins.json` 以及 `texts` 语言文件，并导出为标准的 `.mcpack` 文件。

## 使用方式

1. 在浏览器中打开此链接:https://specsoul.github.io
2. 上传皮肤图片或包含图片的压缩包。
3. 在列表中调整皮肤名称及手臂模型。
4. 填写皮肤包名称与简介，点击“生成皮肤包”即可下载 `.mcpack` 文件。

## 技术栈

- **前端结构/样式**：原生 HTML5 与 CSS3，响应式布局，无第三方 UI 框架。
- **核心逻辑**：原生 JavaScript (ES6+)。
- **图像处理与 3D 渲染**：HTML5 Canvas API 结合 CSS 3D Transforms (`preserve-3d`)。
- **文件打包**：[JSZip](https://stuk.github.io/jszip/) 用于在客户端解析 ZIP 并生成最终的 `.mcpack` 压缩包。
